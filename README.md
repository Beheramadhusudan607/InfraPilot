# InfraPilot

## Real-World DevOps Automation Platform

InfraPilot is a hands-on DevOps project designed to demonstrate practical skills in Linux administration, Git, Docker, CI/CD, Kubernetes, Terraform, and monitoring.

## Project Goals

- Automate application build and deployment.
- Manage infrastructure using code.
- Deploy and manage containerized applications.
- Implement security and monitoring practices.
- Document real-world troubleshooting.

## Technology Stack

- Linux (RHEL)
- Git and GitHub
- Docker
- GitHub Actions
- Kubernetes
- Terraform
- Monitoring and Observability
